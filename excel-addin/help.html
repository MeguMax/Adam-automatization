Devlin Law PDF FormsInstallation and quick guide

Excel PDF Forms

Select one case row in your workbook to generate DC105 Judgment, DC508 Conditional Dismissal (two pages), or MC202 Certification of Records. PDFs stay fillable and are downloaded to your computer.

Download Excel add-inMicrosoft 365 admin center

1. Install Once

For your Microsoft 365 work account, sign in to the admin center as your organization's administrator. Open Settings > Integrated apps > Add-ins > Deploy Add-in, choose a custom add-in, and upload the downloaded devlin-law-excel.xml. Assign it to Just me for your first test. Review the workbook permission and finish deployment yourself.

For a browser-only pilot, open Excel Online and your workbook, then use Home > Add-ins > More Settings > Upload My Add-in if your tenant permits it. This test installation belongs to that browser; Microsoft 365 deployment is preferable for ongoing desktop and web use.

Open Excel with the same Microsoft 365 account. After the add-in appears, select Home > Devlin Law > PDF Forms. If needed, look under Home > Add-ins. Microsoft notes that administrator-deployed add-ins can take 24-72 hours to appear; save your work and restart Excel after installation.

2. Connect

In the right-hand panel, enter your Legal Workflow username and Legal Workflow password, the same credentials used for the admin panel, and select Connect for 12 hours. Do not use your MiFILE or Microsoft password here. Passwords are not stored in the add-in or workbook.

The panel restores its valid connection when reopened. Desktop Excel and Excel Online may each need an initial connection. After 12 hours, connect again. Disconnect ends the current connection.

3. Generate and Save

  1. Open your current workbook. Click any cell in one case's data row, not the header. Check the selected name and case number in the panel.
  2. Choose a Court form, optionally edit File name, then select Generate PDF. Alternatively, select Generate all 3 forms.
  3. Review the preview for an individual PDF and select Download PDF. For three forms, use the download icon beside each filename for separate PDFs, or Download ZIP for one archive.
  4. Find the file in Excel's or your browser's download location, or the folder selected in its save dialog. PDF fields and checkboxes remain editable.

Saving is currently local only. Nothing is automatically saved to OneDrive, emailed, paid, or filed in court. Generating again never changes your workbook. A change to the selected row or its data invalidates the old result so it cannot be downloaded for the wrong case.

Several Cases at Once

Select up to 10 adjacent data rows. Under Multiple cases, check the forms you need and select Generate selected cases. Download separate PDFs using the icons under each ready case, or choose Download cases ZIP for case folders and results.txt. Separate filenames include the source row so cases with the same name do not collide. Your browser may add a suffix if a filename already exists locally.

Hidden rows are skipped; failed cases appear in the panel without preventing the other cases from downloading. A failed case is omitted as a whole, not exported with missing forms. Correct it in Excel and regenerate. Cancel discards all pending files. The panel rechecks the selected rows before every PDF or ZIP download. Changing the selection, mapped values or chosen forms invalidates the result. All PDF fields remain editable; batch generation also saves locally only. Files download one at a time, without needing permission for automatic multiple downloads.

Temporary PDF service failures are retried automatically, up to three attempts per PDF. A retry count appears beside a recovered case. Cancel also stops retry waiting. Data errors are not retried without correction.

Workbook Requirements

Use your supplied workbook with its existing formulas and PDF column names. Row 1 must contain unique headers and a Defendant column. Form columns are dc105_01-dc105_48, dc508_01-dc508_28, and mc202_01-mc202_25. Keep their names unchanged. Optional filename columns are Landlord, Court_Name (or Court), and Case_Number.

Each form uses only its matching columns; ZIP generation checks all three sets. The panel reads the calculated selected row, not a previously saved copy of the workbook. Keep Excel connected to the internet during generation.

When Something Stops

Forms are unavailable or loading timed out
Use Reload forms beside the message. When your internet connection returns, the panel also retries this check automatically. It does not generate or download files on its own.
Reconnecting
Use Reconnect or wait for your connection to return. A temporary outage does not discard a valid 12-hour connection. Do not reinstall the add-in.
No case selected
Select one data row. Use the refresh icon beside Selected case if the name has not updated.
Source issues
Use the cell button beside the issue to select the affected worksheet cell, or Header row for a missing column. Correct the source value or formula in Excel, select the case row again, and regenerate. The add-in does not overwrite or guess the correction.
One case fails in a batch
Use the source-issues arrow beside that failed row to see the exact worksheet cells involved. Other ready cases can still be downloaded while you inspect the issue. Selecting a source cell or changing the workbook invalidates the generated result, so download any ready files you need first. Correct the source, select the desired case rows again, and regenerate. A repeated service error may have no source-cell link; try again when the service is available.
Excel is still calculating
Wait for the workbook's calculations to finish, then retry. Unfinished or error values are not exported silently.
Excel did not respond in time
Use the refresh icon after Excel responds again. If the message persists, close and reopen the PDF Forms panel, then select the case row again. There is no need to reinstall the add-in. A late response is discarded and no PDF is generated from that read.
Text does not fit or preview is unavailable
For a text-fit error, correct the identified cell without losing the required content. If only the preview fails and a download button remains, download and inspect the PDF in your normal PDF application.
Open in Excel or Update Excel
A normal browser tab is not connected to your workbook. Open the installed panel inside Excel. Older Excel versions without Excel API 1.9 support need a current Microsoft 365 Excel version.
